## Important scope and limitations
Portfolio 4 demonstrates JSON document storage using SQLite JSON functions and standalone JSON files, not a dedicated NoSQL database server. Portfolio 5 demonstrates manual snapshot copying and a stale replica; it does not implement live replication, automatic failover, sharding or cloud hosting. Proposed production architecture is explained separately.

Screenshots were categorised by visible content and chronological order. Review the evidence before submission. Screenshots showing errors are retained as test evidence and are not evidence of successful execution.
